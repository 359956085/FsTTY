# 文件管理批量操作

普通点击选择一个条目；Ctrl 点击添加或取消选择，macOS 可使用 Command。Shift 点击按当前列表顺序选择从锚点到目标的连续范围，Ctrl+Shift 可追加范围。列表文字不参与浏览器文字选择，重命名输入框仍可选择文字。点击列表空白清除选区和范围起点。刷新保留仍存在的选项，切换目录重置选区。

右键已选条目保留整个选区；右键未选条目改为单选。多选菜单仅保留下载和删除。批量下载只支持普通文件，选区包含目录或符号链接时下载按钮禁用；删除支持文件和目录。

批量下载一次选择本地保存目录，文件保留远程名称。Rust 后台调度所有会话的下载，最多同时下载 5 个文件，其余按队列等待，有空位后自动补入下一项。界面显示已处理数量、活动下载数量和排队数量，结束后显示成功、跳过及失败数量。文件名称不能安全保存到本地或同批文件名称重复时拒绝创建批次，不会静默覆盖。

遇到本地同名文件，覆盖确认会显示文件名；选择取消会跳过这一项，继续下载其他文件。多个覆盖确认逐个展示。单个文件下载失败不会阻断其余文件。取消传输会停止整个批次，排队项不再启动。下载任务留在 Rust 后台，轻量模式及界面恢复继续使用原任务和队列。

批量删除展示完整条目清单并统一确认，目录及其内容递归删除。各项顺序执行，结束后统一刷新目录。部分条目失败时继续处理其他条目，确认窗口仅保留失败项供重试。
