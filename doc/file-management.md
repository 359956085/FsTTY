# SSH 文件管理：上传、下载与权限

适用于 SSH 文件管理 GUI，版本保持 2.0.2。新增操作通过内部 GUI IPC 完成；MCP 工具、权限策略、数据库和终端实例不变。

## 远端选择与批量删除

普通点击选择一个条目；Ctrl 点击添加或取消选择，macOS 可使用 Command。Shift 点击按当前列表顺序选择从锚点到目标的连续范围，Ctrl+Shift 可追加范围。列表文字不参与浏览器文字选择，重命名输入框仍可选择文字。点击列表空白清除选区和范围起点。刷新保留仍存在的选项，切换目录重置选区。

右键已选条目保留整个选区；右键未选条目改为单选。多选菜单提供下载、修改权限和删除；下载支持普通文件及文件夹，包含不支持项目时禁用下载。

批量删除展示完整条目清单并统一确认，目录及其内容递归删除。各项顺序执行，结束后统一刷新目录。部分条目失败时继续处理其他条目，确认窗口仅保留失败项供重试。

遇到本地同名文件，覆盖确认会显示文件名；选择取消会跳过这一项，继续下载其他文件。多个覆盖确认逐个展示。单个文件下载失败不会阻断其余文件。取消传输会停止整个批次，排队项不再启动。下载任务留在 Rust 后台，轻量模式及界面恢复继续使用原任务和队列。

## 统一上传

工具栏和右键菜单均使用“上传 / Upload”。应用内选择器同时列出本地文件和文件夹，包含名称、类型、文件大小、修改时间；提供主目录、桌面、下载、文档、Windows 磁盘、路径输入及返回上级。

- 首次打开主目录，此后回到本次应用运行期间最后成功浏览的位置。只读取当前目录；单目录最多展示 10000 项，超出时显示提示。
- 勾选或点击行累加选择，Ctrl 多选、Shift 连选、列表 Ctrl+A、空格切换选择；双击或 Enter 进入文件夹。底部保留跨目录选择，可移除单项或清空。选择父目录后去除重复子项。
- 上传按钮显示去重后的根项目数量，空选择禁用。最多选择 256 个上传根项目。
- 打开时固定原标签、连接和远端目录。终端随后改变工作目录不会更改上传目的地；原连接改变时窗口关闭并提示重新打开。拖入文件面板也使用同一后端。
- 选择器只读，不提供本地创建、删除、重命名或编辑。读取失败保留已选项目；迟到读取结果不会替换新目录。Esc 取消并恢复焦点。

## 文件夹传输

上传保留文件夹本身名称及结构，包含隐藏文件和空目录。下载支持文件、文件夹及混合多选；仅下载一个普通文件时继续“另存为”，其余情况选择目标目录。

后端先扫描完整清单，再写入目标；每任务最多 10000 个文件和目录、最大深度 64 层。下载保留已有 10000 个根项目限制，上传保留 256 个根项目限制。扫描可取消，超限、名称冲突及不合法名称在写入前整体拒绝。目录读取使用有界 SFTP 分页。

同名目录合并并保留目标额外内容，同名普通文件继续覆盖／跳过／取消确认。文件与目录类型冲突不会替换目标，报告失败并跳过相关子树。符号链接、Windows 重解析点（包括目录联接）及特殊文件不跟随，计入跳过。下载检查 Windows 保留名、大小写碰撞和路径越界；父子重复选择只处理一次，不自动改名。

复用既有并发下载限制、临时文件和覆盖保护。不打包压缩，不新增权限、所有权或时间戳同步。取消清理当前临时文件，保留完成的文件、目录及目标原有内容。任务区域显示扫描阶段、成功文件／目录、跳过和失败数量。失败与取消分别显示。

## 修改权限

选中文件或目录，右键“修改权限 / Change permissions”。窗口重新读取远端属性，显示所有者、所属组及基础权限。

- 使用所有者／所属组／其他人的读、写、执行复选框，或输入 000～777 三位八进制。多选的不同位显示混合状态，未明确修改的位保持原样；八进制表示明确设置全部九位。无实际修改时禁止提交。
- 目录可选“递归应用到子项”，默认关闭。启用后文件权限、文件夹权限分别设置，默认均保持原样；不自动填入 644／755。
- 仅通过 SFTP SETSTAT 修改权限，保留特殊权限位；不调用 shell、不请求 sudo、不更改所有者／所属组／ACL。符号链接及特殊文件跳过。服务器不支持或权限不足时报告实际错误。
- 递归任务先处理文件及较深目录，最后处理父目录；每项操作前重新检查类型和权限。同一标签／连接的权限任务与传输互斥。
- 可以取消、切换标签、进入轻量模式后接回进度。取消不回滚已完成修改，摘要保留实际成功、失败、跳过和处理范围。已发送的单项 SFTP 修改等待结果后再停止，以便准确计数。

## 生命周期与验证边界

轻量模式只接回后台任务状态，不重复扫描、传输或修改权限。完整退出不增加自动续传。实际服务器行为由其 SFTP 实现与账号权限决定。

自动验证包含真实本机 SSH/SFTP 协议夹具、内容一致性、空目录／隐藏文件、链接跳过、目录合并、冲突保护、扫描上限、部分权限失败、取消、进度接回，以及选择器／权限窗口的交互测试。测试使用隔离临时文件，不访问用户服务器。

首次桌面浏览器验收被控制工具中止，恢复后已在隔离的本地页面补完检查：使用实际 FilesPane、上传选择器、权限窗口和应用样式，演示 API 不访问真实文件／服务器。覆盖中文亮色、英文暗色、409px 窄窗口及 1180×720 窗口、混选、跨目录保留、递归分类、八进制校验和键盘焦点。实测修复了 Esc 关闭上传窗口后焦点未返回按钮的问题。Windows WebView2、原生磁盘／拖放、100%／125%／150% DPI、真实 SSH 服务端权限差异和轻量模式端到端仍待人工验收。详见 optimization-validation.md。

## 批量传输统计

上传和文件夹／批量下载完成扫描后，卡片显示“总文件／总目录”，另行显示文件成功、目录完成、跳过和失败数量；下载进行中同时显示活动与排队数量。总数按去重后的可传输清单统计，目录包含所选根目录及空目录，隐藏文件照常计入。链接和特殊文件计为跳过，不计入普通文件／目录总数。

扫描期间不显示估算总数；取消或部分失败后保留已扫描总数。旧任务缺少总数字段时只显示原有进度，轻量模式接回同一个后台任务继续显示计数。长文本可换行，卡片随状态增高。
