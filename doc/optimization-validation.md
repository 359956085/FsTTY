# FsTTY 优化与交互验收

## 首轮：性能与交互保护

日期：2026-09-29。源码基线：`695a79f`，结果来自本轮工作区修改。

本轮实现 MCP 缓存连接回收、可见设备面板快照轮询、文件面板渲染隔离。设置页及弹窗保持原有加载方式，没有新增懒加载、文件列表虚拟化、安装器改造或依赖集中升级。外部 MCP、Tauri IPC、配置和数据库结构不变。

### 实现边界

- MCP 工具持有内部连接守卫直至调用结束，错误与请求取消也会释放使用计数。最后一个使用者退出后才开始计算 300 秒空闲时间。每个新缓存连接只有一个回收任务，复用会唤醒并重新计时，替换会使旧任务退出。网络操作不持有缓存表锁，回收仅按 MCP 连接 ID 断开。
- `useSessionConnections` 通过内部 `devicePollingRuntimeId` 选择观察对象，仅当会话页可见、右栏展开且活动标签已连接时读取快照。Rust 采样继续运行；恢复时立即读完整历史，有历史时沿用已有画面和加载状态。
- 同一标签的同一连接复用未完成的快照读取，通过轮询代次、请求代次与连接 ID 隔离旧响应。重连可以从新的时间起点开始，慢快照不会阻塞文件请求。
- 文件面板使用 React 默认浅比较和稳定回调。所有文件操作都依赖当前标签及实际使用的函数，保留原组件 key、选择及拖放状态归属；文件、目录、传输和语言变化仍会更新。

## 第二轮：会话表单与更新日志焦点修复

日期：2026-09-30。源码基线：`bd57707`，结果来自本轮工作区修改。

### 实现边界

- 共享 `useDialogFocus` 仅用于会话表单和更新日志，负责首次聚焦、动态排除隐藏/禁用控件、Tab 首尾循环、无可用控件时聚焦容器，以及关闭后的焦点恢复。最新回调和忙碌状态通过 ref 读取，语言及普通重渲染不重置焦点；其他弹窗已接管焦点时不会抢回。
- 会话表单通过标题关联提供名称，打开时聚焦主机。Esc 尊重输入法组合与子控件的 `defaultPrevented`；分组和认证菜单先收起，下一次 Esc 才关闭表单。Esc 与关闭按钮共用忙碌保护，保存/管理凭据期间均不能关闭，保留原有保存、校验和蒙层行为。
- 两个新建入口分别记录实际按钮；右键编辑在菜单卸载前记录会话行，关闭后返回该行。行消失或不可见时使用标签栏新建按钮；目标已卸载则不强行聚焦。
- 更新日志继续使用原有 lazy/Suspense。关于页持有完整焦点生命周期，加载占位和正文注册当前容器；加载中可用关闭按钮、Tab 和 Esc，内容到达时不会先恢复背景焦点，取消后的加载结果不会重开弹窗。
- Windows 检查发现 WebView2 会让滚动正文成为隐式 Tab 停靠点，已允许浏览器从内部焦点自然前进，并为日志正文明确设置可聚焦的命名区域。蒙层的 mousedown 取消默认焦点转移，避免覆盖关闭时恢复的入口焦点。
- 不新增依赖；其他弹窗、终端、轮询、文件面板、公开 MCP/IPC、配置及数据库保持原范围。Workspace 仅透传新建按钮的 ref 和点击事件。
