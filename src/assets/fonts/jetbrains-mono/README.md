# JetBrains Mono 2.304

Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).

Unmodified upstream WOFF2 fonts from the fixed release:
https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304

FsTTY bundles Regular (400), Bold (700), Italic (400), and BoldItalic (700).
The four fonts total 380,768 bytes (371.84 KiB); the original OFL.txt is 4,399 bytes.
Exact upstream URLs, byte lengths, and SHA-256 hashes are in manifest.json.

Licensed under the SIL Open Font License 1.1; see OFL.txt. The original font
files are not renamed or modified. The internal CSS family alias
"FsTTY JetBrains Mono" only isolates application rendering from installed fonts.

The fonts are embedded in the frontend build. The license, this notice, and the
manifest are also included as installer resources under third-party/jetbrains-mono.
No runtime downloads, system font registration, or font installation occurs.
